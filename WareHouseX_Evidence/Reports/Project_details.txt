DEPLOYMENT TOPOLOGY:
- Application Directory:      /home/rashmigowda/WareHouseX
- Production Scripts & Bin:   /opt/warehousex
- Backup Storage Vault:       /var/backups/warehousex
- Log Journals:               /var/log/warehousex
- Systemd Daemon Unit:        /etc/systemd/system/warehousex.service
- Cron Automation Schedule:   /etc/cron.d/warehousex-backup
- Firewall Framework:         Ubuntu Uncomplicated Firewall (UFW)
- Monolithic Storage Layer:   LVM2 Volume Group (vg_warehousex) with Ext4 Partitions

SECURITY & ROLE-BASED ACCESS CONTROLS:
- Administrators Group:       warehouse-admins (UID/GID privileged Linux group)
- Operations Staff Group:     warehouse-staff (Restricted to inventory catalog)
- Sudoers Configuration:      /etc/sudoers.d/warehousex (Restricted command allowlist)
- OpenSSH Hardening:          Port 22, PermitRootLogin no, PasswordAuthentication no
- Two-Stage Restore Protocol: Explicit confirmation keyword ("RESTORE") before overwrite
